# McCain Galaxy Browser

A standalone SwiftUI iOS/iPadOS browser using WebKit and McCain Capital's cinematic galaxy visual language.

## Included

- Standard and private tabs
- URL entry and Google search
- Back, forward, reload, and swipe navigation
- WebKit-native downloads into the app's `Documents/Downloads` directory
- Persistent download index, Files app access, sharing, and deletion
- iPhone and iPad support on iOS 17+

## Run

1. Open `McCainGalaxyBrowser.xcodeproj` in Xcode.
2. Select the app target, then choose your Apple development team under Signing & Capabilities.
3. Select an iPhone simulator or connected device and press Run.

The placeholder AppIcon asset intentionally has no image. Add a 1024x1024 icon in Xcode before distributing the app.
